# Electerm Terminal 定制版交付

基于 Electerm 5.11.8，原始提交 `0b3bd8e9`。经典界面版本：R7。

2026-11-23 核对上游至 `c7bda4ec`。仅移植 `561f0f36`（启动时共享 WebSocket 握手）、
`4f6b1381`（主窗口导航与 IPC 来源校验）、`dd035f29`（ZMODEM 同名下载保留扩展名）。
未合并上游界面、按键或依赖更新，包版本仍为 5.11.8。

## 程序

- Windows x64：`dist/classic-r7/Electerm-Terminal-5.11.8-win-x64.zip`。
- 本机直接启动：`dist/classic-r7/Electerm-Terminal-5.11.8-win-x64/Electerm Terminal.exe`。
- Apple Silicon ARM64：`dist/classic-r7/Electerm-Terminal-5.11.8-mac-arm64-unsigned.zip`。

便携版使用 EXE 旁的 `.runtime` 保存书签和设置；两个分发 ZIP 均不包含用户数据。

Windows 是免安装文件夹版。解压整个 ZIP 后运行其中的 EXE，不要单独移动 EXE。
未做发布者签名，系统可能提示未知发布者。

Mac 包使用官方 Electron ARM64 运行时，主程序、PTY 模块、spawn-helper 均已核对为 ARM64。
Windows 不能完成 macOS 原生打包、签名和运行验证，因此该包是离线组装的未签名候选包，
不是已经通过 M5 实机验收的发布版。

在 Mac 上解压到可写目录，打开终端，进入解压目录，执行：

```bash
bash Prepare-Mac.command
```

脚本只给这个应用补齐执行权限、进行本地 ad-hoc 签名并校验后启动，不安装全局依赖，
也不关闭 Gatekeeper。系统若仍拦截，需要按 macOS 对单个应用的安全提示确认。
包内名称是 `Electron.app`，显示名称为 Electerm Terminal。
本地签名不等于 Apple Developer ID 签名或公证；M5 上的启动、休眠恢复和长连接仍须实机验证。

## 改动前后

**R7：** 两种界面主题都使用本机 MobaXterm 23.2 的 16 个 ANSI 色值和前景、背景、光标色。
SSH 展开文件栏时，快速连接位于左栏上方，标签从终端左缘开始。文件列表按实际视口虚拟滚动，
终端完整字符行底部贴齐底栏；无需固定预留高度。

**R6：** 同一窗口的 SSH 标签共享 SFTP 宽度；松开分隔条后应用到已开和新开的标签，
收起状态仍按标签独立。文件列表为 12 px 字、21 px 行距；页签栏为 28 px。
新建书签和书签列表使用独立图标。监控开关和 CPU 历史柱图移入 24 px 底栏，
不再单占一行。普通终端输出默认对错误、警告、成功状态和 IPv4 格式文本着色；
已有关键词配置优先。监控没有增加采样频率。

**R5：** 本地或 SSH 终端断开后，焦点在该终端时按 `r` 或 `R` 即可重连。保留标签的位置和编号，
滚动可查看断线前的输出，受原滚动缓冲行数限制。重连建立新的 shell，不恢复原进程或环境变量。
正常连接以及在其他输入框输入 `r` 都不会触发此快捷键。

桌面顺序为工具栏（含当前会话的 SFTP 开关与目录同步）、标签行、终端；手机保留原折叠菜单。
终端默认字号 13，保留已有字号覆盖。SSH 左侧文件浏览器默认占 20%，文件行距 26 px，
移除路径收藏星标。SSH 底部仪表按钮开关远程监控，默认关闭，关闭后停止周期采样；
Linux 指标依赖服务器允许执行相应只读命令，本地终端没有该开关。

R5 在 Windows 成品中测试了本地 PowerShell 断连后按 `R`、回环 SSH 断连后按 `r`，核对标签编号、
旧输出和新 shell 输入。另测监控开关以及关闭后停止采样、文件行高、面板宽度和目录跟随。
165 项定向单测通过。截图见 `.cache/classic-r5-monitor.png`，Mac 未进行实机验收。

**R4：** 桌面单窗的 56 px 工具栏和 36 px 页签栏合并成一条 36 px 操作栏。分屏保留各自的页签。
Windows 默认隐藏单独的应用菜单行，保留原生窗口标题栏和菜单快捷键。移除桌面左侧重复入口；
会话书签从文件夹按钮打开，有传输记录时在顶栏显示传输入口。终端正文字号未改。
快速连接移除没有动作的闪电按钮，地址为空时禁用连接箭头。双击页签内的图标不再用字符串方式判断 SVG 类名；
从溢出菜单选择页签与直接点击页签走同一条路径，避免显示的终端与当前操作对象不一致。

R4 的 Windows 成品验证了 150% 缩放下最大化关闭配置、窄窗从溢出菜单切换和关闭页签、
深浅切换、分屏、纯黑本地 PTY、回环 SSH 和左侧 SFTP 目录跟随。最小化 130 秒后原 PowerShell
和 SSH shell 仍可用；另测旧 WebSocket 延迟关闭未终止新通道。测试中未捕获页面异常。
最后一次短时空闲采样：本地私有内存 597 MiB、整机 CPU 0.21%；本地加 SSH/SFTP 为
604 MiB、0.19%。开关过额外页签，不能由单次采样断言比原版省内存。
报告：`.cache/classic-r4-report.json`；应用截图：`.cache/classic-r4-ssh.png`。
未验证真实外网长连接或 Mac 实机。额外的隔离测试目录仍在项目 `.cache` 中，未打入 ZIP。

Windows 最终包通过快速连接框接入回环 SSH。最小化空闲 130 秒后，本地 PowerShell 保留
同一 PID 与变量，SSH 未重建 shell，SFTP 跟随到了新目录。没有模拟整机休眠、真实 VPN 或长时间外网连接。

## 稳定性与目录跟随

修复了可复现的会话登记竞争和目录初始化时序问题，保留原有连接、认证和重连机制。
不能据此认定所有“运行一段时间后断连”都已根治；网络、服务器策略、系统休眠等
仍可能断开连接。调试模式会记录终端传输关闭码和原因，便于后续定位。

保留原有 SSH 协议层保活，不默认发送回车来绕过服务器空闲策略。
目录跟随仍依赖原有 Shell Integration；受限 shell、不允许注入的设备或特殊提示符
需要实机验证。不会在检测到尚未提交的用户输入时强行注入脚本。

## 资源实测

Windows 本机，16 个逻辑 CPU，Playwright 驱动的打包程序，新建隔离配置；
每种状态约 16 秒空闲窗口。统计应用完整后代进程树，包含后台服务、PTY 和本地 PowerShell，
不包含测试 SSH 服务器。SSH 状态仍保留前面的本地终端页签。

| 状态 | 私有内存合计 | 工作集合计 | CPU 占整机 |
| --- | ---: | ---: | ---: |
| 1 个本地终端 | 457 MiB | 791 MiB | 0.24% |
| 本地 + 1 个 SSH/SFTP | 527 MiB | 912 MiB | 0.26% |

工作集合计重复计算共享页，不能当成实际独占物理内存。私有内存是 Windows
PrivateMemorySize64，不等于活动监视器在 macOS 上的内存口径。
测试有调试连接和短时采样，数值不是上限或长期稳定性结论。
原始报告见 `.cache/smoke-report.json`，截图见 `.cache/windows-*.png`。

已减少功能加载、后台任务和本地文件扫描，但 Electron 及原有每会话后端进程的基础开销仍在。
未做原版同条件 A/B 对照，不能保证每个场景都比原版更省内存/CPU。
不通过重写会话架构追求大幅减重，以免扩大本次回归风险。

## 环境与重建

项目位置：`D:\share\electerm\electerm`。
开发依赖在 `node_modules`，缓存在 `.cache`，暂存输出在 `work`，交付在 `dist`。
没有新增 npm 依赖或安装全局工具。

从干净依赖环境初始化时，在仓库根目录使用：

```powershell
$env:npm_config_cache = "$PWD\.cache\npm"
$env:TEMP = "$PWD\.cache\tmp"
$env:TMP = $env:TEMP
New-Item -ItemType Directory -Force $env:TEMP
npm ci --ignore-scripts --legacy-peer-deps --no-audit --no-fund
node src/build/bin/build-terminal.js both
```

脚本复用现有依赖和原有 Vite 构建，一次准备前端、生成两个包；若新输出目录的 EXE 旁已有
`.runtime`，Windows 打包会停止，不清空使用中的便携配置。
离线 Mac 打包需要 `.cache/electron/electron-v44.7.0-darwin-arm64.zip`；
Windows 使用同目录的 `electron-v44.7.0-win32-x64.zip`。
本次已下载官方运行时并核对官方 SHA256。

运行数据默认在程序旁的 `.runtime`；Windows 解压到当前项目目录即可保持数据也在此目录。
若程序目录不可写且没有显式 `DATA_PATH`，会回退到系统应用数据目录。
显式 `DATA_PATH` 不可写则报错，不静默换位置。SSH 主机指纹保存在该数据目录的
`.ssh/known_hosts`，私钥仍按用户配置读取，不复制或搬动系统私钥。

两个 ZIP 可以独立分发，不需要带源码、开发依赖或构建缓存。
发布包不是“零占用”原生终端；未来继续极限减重需要单独评估架构改造。

初版交付时目录合计约 2 GiB，主要为 `node_modules` 约 698 MiB、`dist` 约 668 MiB、
`.cache` 约 543 MiB；ZIP 分别约 151 MiB（Windows）和 129 MiB（Mac）。
已尝试清理构建暂存和旧测试目录，但删除操作被当前执行环境策略拦截，未实际删除；
这些是可再生文件，不是额外安装的运行环境。保留了最新测试报告和截图。
